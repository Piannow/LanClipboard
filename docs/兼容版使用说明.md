# 局域网剪切板 v1.1 兼容版

这是 [AstrBotLite](https://github.com/Piannow/AstrBotLite) 的机顶盒辅助工具，用于省去用遥控器填写人设卡、提示词等长文本的麻烦：在手机发送文字，到机顶盒剪切板后直接粘贴。

## 本次兼容目标

新增对一类常见运营商定制 Android IPTV 机顶盒的支持：运行 Android 4.4～5.1 的老旧盒子，例如华为 EC6108、中兴 B860AV、创维 E900 等同系统版本设备。实际能否安装及后台运行仍取决于厂商系统限制，未声称已经在这些具体型号上实测。

保留原手机发送、机顶盒接收、自动同步、手动 IP、浏览器发送、UDP 自动发现及 HTTP 9527 / UDP 9528 协议。版本从 1.0 升为 1.1，签名与旧版一致，可尝试直接覆盖升级。

## 兼容性改进

- 最低 Android 版本由 6.0（API 23）降至 4.4（API 19）。
- 同时提供普通应用入口和 Android TV Leanback 入口，附 TV banner。
- 触摸屏、Wi-Fi、以太网和 Leanback 均为非必需硬件能力；纯有线机顶盒不会因缺少 Wi-Fi 被安装器过滤。
- 遥控器方向键可聚焦操作，按钮聚焦有描边，电视入口默认聚焦接收端。
- 适配旧系统通知、PendingIntent、Holo 主题；API 21 以上再启用 Material 主题和字距。
- 接收文字先写固定文件；新版系统可使用无障碍全选复制，失败或不可用时直接写系统剪切板。
- Android 4.4～5.1 使用直接写剪切板方案，不依赖较新的无障碍 View ID 查找能力。
- 无障碍设置入口不可用时回退到系统设置；透明复制窗口增加焦点和选择文本处理。

## 安装

APK：`局域网剪切板-v1.1.apk`

可通过 U 盘、盒子自带应用安装器或 ADB 侧载：

```bat
adb connect 机顶盒IP:5555
adb install -r 局域网剪切板-v1.1.apk
```

若提示签名不一致，先备份需要保留的数据，再卸载旧版后安装；不要无故卸载，避免丢失接收记录。

## 使用

1. 手机和机顶盒连接同一局域网，关闭路由器的 AP/客户端隔离。
2. 在机顶盒安装并打开应用，选择“机顶盒 / 电视端 · 接收剪切板”，启动接收服务。
3. Android 6.0 及以上可开启“剪切板同步复制服务”无障碍权限；若系统无此设置，可关闭“无障碍全选复制（兼容模式）”，使用直接写剪切板和固定文件。
4. 在手机安装同一 APK，选择“手机端 · 发送剪切板”，扫描并选择接收端；扫描不到时手动输入机顶盒 IP。
5. 点击“发送文本”，或开启“自动同步（复制即发送）”。
6. 还可在手机浏览器打开 `http://机顶盒IP:9527` 发送文字。
7. 固定文件为应用专属目录中的 `剪切板.txt`，每次覆盖写入。没有外置存储时回退到应用内部目录。

## 真机验收建议

安装后依次确认：遥控器能进入接收端；服务显示运行中；手机能扫描或手动连接；发送中文与多行文本后盒子显示接收计数；目标应用可粘贴，或 `剪切板.txt` 内容正确。若服务被定制系统杀死，需要在盒子的后台运行/自启动管理中允许本应用。
